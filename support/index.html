Support

Found a bug, missing a feature, or stuck? Open an issue on GitHub — every report is read. Please include your macOS version and, if you can, the Markdown file that shows the problem.

The full guide is inside the app: Help → Markus Help.

What does Markus need?

macOS 26 Tahoe or later on a Mac with Apple silicon. The Apple Intelligence features — summaries, Ask, Explain and Diagram Selection — also need Apple Intelligence turned on in System Settings; on other Macs they stay hidden and everything else works.

How do I open my documents?

File → Open Vault… (⇧⌘O), the + button in the sidebar, or drag a folder onto the window. Markus keeps the folder in the sidebar as a vault and opens it again next time. Single files open with File → Open File… (⌘O) or by dragging them onto the window.

Can I edit documents in Markus?

No — Markus is a reader, made to sit next to the editor you already use. Right-click a file and choose Open in to send it to your editor; pick the editor in Settings → General. When you save, Markus updates the page right away.

The Quick Look preview isn't from Markus

Markus needs to be in the Applications folder. If another app's Markdown preview shows up instead, turn the others off in System Settings → General → Login Items & Extensions → Quick Look.

A GitHub repository says the request limit is reached

GitHub allows 60 requests an hour without an account, and opening a repository takes a few. A read-only token in Settings → Accounts raises the limit and opens private repositories. The token stays in your Mac's Keychain.

A diagram or formula doesn't render

Mermaid diagrams need a ```mermaid fence; math uses $…$, $$…$$ or a ```math fence. If it still fails, the error is shown in place of the diagram — please send it with the source in an issue.
